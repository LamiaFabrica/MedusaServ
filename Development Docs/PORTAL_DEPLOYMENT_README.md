### 🔧 Installation Instructions

#### Prerequisites
- PsiForceDB server running on 172.236.23.54
- Web server with Lamia template support
- PFQL 2025 Complete Command Reference
- Yorkshire Champion Gold Standard compliance

#### Quick Installation
```bash
# Extract deployment package
tar -xzf portal-services-complete.tar.gz
# OR
unzip portal-services-complete.zip

# Copy files to web portal directory
cp -r PFQL-Portal-Services-Yorkshire-Champion/* /path/to/web/portal/

# Set proper permissions
chmod 755 web/portal/components/*.lamia
chmod 755 web/portal/pfql-form-processors.lamia
```

#### Database Configuration
