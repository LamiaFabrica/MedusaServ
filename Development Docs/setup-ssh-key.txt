Step 4: Deploy MedusaServ Package
----------------------------------

Once passwordless SSH works, you can deploy:

# Install
cd /opt/medusaserv
sudo ./scripts/install.sh

# Start services
sudo ./scripts/start.sh

# Check health
sudo ./scripts/health-check.sh

========================================
TROUBLESHOOTING
========================================

If connection still asks for password:
1. Make sure you ran the commands in LISH console
2. Check file permissions on server: ls -la ~/.ssh/
3. Try: ssh -v medusadb (verbose mode shows what's happening)

If you're completely locked out:
1. Use Linode's "Reset Root Password" feature
2. Reboot server
3. Then add the SSH key via LISH console
