MSVC COMPILER VERSION CHECKING
================================================================================

All CMakeLists.txt files now include:

if(MSVC)
    if(CMAKE_CXX_COMPILER_VERSION VERSION_GREATER_EQUAL 19.40.0)
        set(CMAKE_CXX_FLAGS "${CMAKE_CXX_FLAGS} /std:c++latest /permissive-")
    else()
        message(FATAL_ERROR "MSVC compiler version ${CMAKE_CXX_COMPILER_VERSION} does not support C++26. Requires MSVC 19.40+")
    endif()
else()
    set(CMAKE_CXX_FLAGS "${CMAKE_CXX_FLAGS} -std=c++26")
endif()

COMPILER REQUIREMENTS
================================================================================

MSVC (Windows):
- Version: 19.40.0 or later (Visual Studio 2025+)
- Flag: /std:c++latest
- Will FATAL_ERROR if version insufficient

GCC (Linux/WSL):
- Version: 13.0 or later
- Flag: -std=c++26
- Will error if version insufficient

Clang:
- Version: 17.0 or later
- Flag: -std=c++26
- Will error if version insufficient
